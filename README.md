# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения результата в PDF.

Приложение предназначено для предпринимателей, которые готовят коммерческие предложения клиентам, и офисных сотрудников, которые составляют сметы закупок и расчёты расходов для руководителя.

## Файлы приложения

Планируемая структура приложения:

- `index.html` — структура страницы: поля для позиций сметы, кнопки и итоговая сумма.
- `styles.css` — оформление страницы и адаптация для телефона.
- `script.js` — обработка ввода, расчёт сумм и подготовка результата к сохранению в PDF.

Сейчас созданы только `README.md` и `AGENTS.md`. Файлы приложения будут добавлены по отдельному запросу.

## Как открыть

Когда будет создан `index.html`, откройте его двойным щелчком. Приложение будет работать в браузере без установки дополнительных программ.

## Как проверить

После реализации расчёта добавьте две позиции:

1. Количество — 2, цена — 15 000 ₸.
2. Количество — 1, цена — 8 000 ₸.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
